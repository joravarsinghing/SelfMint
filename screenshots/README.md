# Screenshots

Drop PNG screenshots in this folder so the images render in the root `README.md`.

Recommended files (exact names):

- `tasks.jpg` — Tasks tab (show add/reorder if possible)
- `rewards.jpg` — Rewards tab (show wallet + redemption section)
- `dashboard.jpg` — Dashboard (graphs visible)
- `tags.jpg` — Tag editor / tag assignment UI

Tips

- Use dark mode screenshots (SelfMint’s default look).
- Keep the status bar visible for “real app” credibility, or crop consistently across all shots.
- Aim for ~1080px wide (or device-native) PNGs.
